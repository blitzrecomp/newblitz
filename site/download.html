Download New Blitz

Get New Blitz for your computer. It sets up your phone, handheld, PS5 or an N64 or emulator export too: its Blitz Builder sends each one the game with your ROM and your setup already in, so it starts ready to play.

How the Builder does it

Every download is on the latest release page on GitHub, with its SHA-256 checksum. No computer? Install on a phone by hand. Rather unzip than install? The same page has a .zip for Mac and Windows and a .tar.gz for Linux. Older versions: all releases.

You'll need

Your own copy of the game. New Blitz needs a dump of your own NFL Blitz 2000 (USA) cartridge, v1.1 or v1.0 (a v1.0 dump is updated to v1.1 as it goes in), as a .z64, .v64 or .n64 file, or a .zip holding one. No game assets come with New Blitz, and nobody here can send you a ROM. The app checks the file is exactly the right cartridge, and tells you what's wrong if it isn't.

You make a ROM from your cartridge with a cartridge reader: a small USB device that copies the cartridge to a file.

Opening it the first time

The downloads aren't signed with a paid developer certificate, so your device asks before it opens them the first time. That's expected. You only do this once.

Windows

  1. Run Windows-Setup.exe. If SmartScreen says "Windows protected your PC", click More info, then Run anyway.
  2. Click through the installer, and open New Blitz from the last page or from Start.
  3. To remove it later: Settings → Apps. Your saves and settings stay, so a reinstall picks up where you left off.

Mac

  1. Open the .dmg and drag New Blitz to Applications.
  2. Open the app once. macOS says it can't be opened: close the message.
  3. Open System Settings → Privacy & Security, scroll down, and click Open Anyway next to the app's name. Confirm, and it opens. From then on it opens normally.

Linux

  1. Make the AppImage executable: chmod +x on the file (or tick "Allow executing" in its properties).
  2. Run it.

Checking a download

Each release lists the SHA-256 checksum of every file. To check yours matches, run the command for your system on the downloaded file and compare the result with the release page:

SystemCommand
Macshasum -a 256 <file>
Windowscertutil -hashfile <file> SHA256
Linuxsha256sum <file>

Only download New Blitz from the release page linked here. It's always free: if someone's charging for it, it isn't from us.

Set up from your computer

The Builder does the rest

The computer is the hub. Its Blitz Builder sends each device the game with your ROM and your setup already in, so it skips the ROM and setup questions and starts ready to play.

  • Android TestedSent over USB with adb, ROM and all.
  • Dual-screen BetaThe same Android app, on two-screen handhelds.
  • iPhone / iPad PreviewSaved as an .ipa with your ROM inside, for you to sign with your own Apple account.
  • PS5 PreviewA jailbroken console with etaHEN, over your network.
  • N64 or an emulatorExport ROM writes a cartridge-ready .z64.

Advanced: install by hand

No computer to set it up from? The release page also has the Android app (.apk) and the iPhone app (.ipa). Install it yourself, then pick your ROM on the device: its first screen says how to set it up from a computer, with Pick a File Instead below.

Android

Android 10 or later on a 64-bit ARM chip with Vulkan graphics. Two-screen handhelds too.

  1. Open the .apk on the device. Android asks to allow installs from your browser or file manager: allow it, then install.
  2. Open New Blitz and choose Pick a File Instead to pick your ROM.

iPhone and iPad

iOS 17 or later, signed with your own Apple account.

  1. Install Sideloadly on a Mac or Windows PC, plug the iPhone in, drag the .ipa in and sign in with your own Apple ID. A free one works.
  2. Turn on AutoRefresh (the circular-arrows button left of Start), so it renews itself over the same Wi-Fi.
  3. On the phone, trust your Apple ID in Settings → General → VPN & Device Management, and turn on Developer Mode if it asks.
  4. Open New Blitz and choose Pick a File Instead, or share the ROM to New Blitz from the Files app. Every step, and the other options, are in Get started.

The .apk and .ipa

Build it yourself
